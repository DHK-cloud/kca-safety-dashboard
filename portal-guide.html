보고는 간단하게,
자료는 화면에서 관리합니다.

운영: KCA 부산본부. 기존 홈페이지와 기상 시트는 보존합니다.

안전점검·작업중지권

  1. 보고를 선택하고 이름·소속·날짜·주소를 확인합니다. 위치 사용을 허용하면 주소를 추정합니다.
  2. 날씨와 위험을 확인하면 해당 조건의 조치만 추천합니다. 실제 조치·진행 상태와 휴식 시간을 선택하고 확인해 저장하세요.
  3. 작업중지권 사진은 선택하거나 촬영할 수 있습니다(선택 사항, 최대 3장).
  4. Google 로그인 후 저장합니다. 미등록 직원은 열람 비밀번호로 보고 권한을 확인할 수 있습니다.

이후 내 기록에서 날짜를 정정할 수 있습니다. 최초 저장 시각은 유지하고 정정 전후 내용을 이력으로 보관합니다. 작업중지 기록은 안전담당관에게 직접 보고하는 절차를 대신하지 않습니다.

교육자료를 올릴 때

  1. Drive에 파일을 올립니다. 영상 처리 완료를 기다립니다.
  2. 관리자에서 자료 등록을 누르고 제목·분류·형식·파일 링크를 입력합니다.
  3. 새 교육자료의 열람 기본값은 공개입니다. 보호가 필요한 자료는 비밀번호·허용 계정으로 바꾸세요. 기존 자료 수정은 저장된 열람 설정을 유지합니다.

보고 사진은 별도 업로드 방식으로 처리됩니다. 교육영상처럼 큰 파일은 Drive에 보관합니다.

관리자 로그인

Google 로그인과 관리자 아이디 로그인을 함께 제공합니다. 처음에는 Google 관리자로 로그인하여 포털 설정 → 관리자 아이디·비밀번호 설정에서 직접 계정을 만드세요. 관리자 비밀번호는 8자 이상이며 자료 열람용 비밀번호와 별개입니다. 변경하면 이전 자체 로그인은 만료됩니다.

교육자료는 캠페인과 연결하지 않습니다. 월간 캠페인 자료는 운영 관리 → 캠페인에서 해당 항목의 ‘캠페인 자료 추가’로 별도 등록합니다.

열람 단계

  • 공개: 안전캠페인은 로그인 없이 사진·영상을 바로 열람합니다.
  • 비밀번호: 운영자가 정한 공통 비밀번호로 열람합니다(숫자 4자리 또는 문자 4자 이상). 관리자 설정에서 직접 만들거나 변경합니다.
  • 허용 계정: 등록된 Google 계정만 포털에서 열람합니다.

보호 자료도 제목을 미리 표시합니다. 블라인드를 선택하면 제목까지 숨깁니다. Drive의 ‘링크가 있는 모든 사용자’ 자료는 원본 링크를 아는 사람이 포털 비밀번호 없이 볼 수 있습니다. 허용 계정 전용 자료는 Drive도 ‘제한됨’으로 설정하고 대상 계정만 뷰어로 지정하세요. 포털과 Drive 권한은 별개입니다. YouTube에 등록하지 않습니다.

저장과 비용

기록과 콘텐츠 목록은 비공개 Google Sheets, 보고 사진은 비공개 앱 생성 Drive 폴더에 보관합니다. 브라우저 데이터를 지워도 클라우드 기록은 남습니다. Drive 권한은 앱에서 사용하는 특정 파일(drive.file)만 이용합니다.

추가 결제 계정·유료 API·도메인은 연결하지 않습니다. 기존 Google 구독 저장공간을 사용하며 Apps Script와 Drive의 무료 사용량 제한은 적용됩니다. 제한에 도달하면 기능이 일시 중단될 수 있습니다. Google 사용량 제한

첫 화면에는 공개 목록을 바로 표시하고 최신 목록을 뒤에서 갱신합니다. 공개 조회는 최대 1분간 재사용하고 관리자 수정 시 서버 목록 캐시를 무효화합니다. 직원 자료는 방문 중 메모리에만 잠시 재사용합니다.

위치와 기상

안전점검 주소를 확인하면 대표지역 체감온도·기온·평균/순간풍속·강수·강설·적설과 기상청 육상 특보를 자동으로 불러옵니다. Open-Meteo 수치예보이며 관측값이나 낙뢰 탐지값은 아닙니다. 기상청 특보는 주의보·경보·예비를 구분하며 조회 실패를 특보 없음으로 표시하지 않습니다. 현장 수치로 정정할 수 있고 출처·기준 시각도 기록에 보관합니다. 과거 날짜에는 현재 예보를 채우지 않습니다. Open-Meteo 자료·무료 비상업용 사용 한도

Apps Script 내장 Google Maps 주소 변환으로 좌표를 주소로 추정합니다. 위치 사용을 허용할 때만 조회하며 정밀 좌표는 보고에 저장하지 않습니다. 주소는 수정 가능합니다. 부산본부 관할 밖에서는 지역 기상을 생략합니다. 기존 기상 시트 A11:K30 및 G5:G6을 읽고 수집 시각을 표시합니다.

설치 담당자용

apps-script/Code.gs와 JwtLibrary.gs, appsscript.json을 사용합니다. 기존 운영연결정보.html의 시트·클라이언트·관리자 설정을 유지하세요. 이 비공개 파일은 GitHub에 올리지 마세요.

Drive API v3 서비스와 drive.file 범위를 사용하고 setupPhotos로 비공개 사진 폴더를 초기화합니다. 기존 웹앱 배포를 새 버전으로 갱신하여 URL을 유지합니다. 공개 배포 파일은 portal-preview.html과 portal-guide.html 두 개입니다. 기존 index.html은 변경하지 않습니다.

Google OAuth 테스트/조직 정책은 실제 직원 계정으로 확인해야 합니다. 운영 전 사진 저장·보고 정정·공개/비밀번호/계정 열람과 실제 기기 GPS를 확인하세요.

기준: 제공된 KCA 무선국검사 안전매뉴얼 KCA-KSJ-01 Rev.4(2026.07.07), 작업중지권 26~27쪽·양식 35쪽·폭염/한파 표 39~40쪽. 자동 조치 초안은 실제 조치 완료를 대신하지 않습니다.
